# Использование 💎

**Перед запуском подпишите сообщение в уведомлениях на сайте метеоры для каждого используемого кошелька, если еще этого не сделали!**

Для запуска наблюдения за акаунтами на вкладке Запуск нажмите Начать - это начнет открывать позиции и впоследствии будет за ними следить. Прекратить означает прекращение работы наблюдения, то есть отмена транзакций и бездействие.\
\
Кнопка Закрыть закроет все открытые на аккаунтах позиции, преращение этой функции отменит запущенные транзакции.

При обновлении конфигурации/профиля требуется перезапустить процесс (прекратить/начать заново)
