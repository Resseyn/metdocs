# Конфигурация 🛠

Далее введите ключ, выданный вам при покупке. ВАЖНО: один ключ можно использовать только на одном устройстве! При необходимости отвязки устройства от ключа обращаться к разработчику.

После этого вы можете беспрепятственно использовать софт.

_При конфигурации учтите, что софт по дефолту использует все средства для выбранного пула и поддерживает только один пул на аккаунт!_
