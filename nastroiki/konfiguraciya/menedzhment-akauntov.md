# Менеджмент акаунтов 💻

1. Заполните Приватный ключ кошелька (ОБЯЗАТЕЛЬНО)
2. Заполните Ключ пула - для каждого приватного ключа нужен свой пул. Его можно получить из адресной строки браузера, когда вы открываете пул (ОБЯЗАТЕЛЬНО, уникально для полной версии)

> https://app.meteora.ag/dlmm/39deGQ4Ucue7tGXRDRHvRLz8zZQ6tu7QFkKq5UYiDQ9N - символы после последней / - это ключ пула

<figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>

3. Для каждой позиции можно выбрать свой бинстеп вправо и влево (МАКСИМУМ 34, т.к максимальный диапазон пула DLMM - 69)
4. Стратегия пулов на метеоре
5. Проскальзывание позиции. По дефолту 3, если вы трейдите пулы, где бин двигается очень быстро - рекомендуется повысить.
6. Оставить SOL - для каждого приватного ключа определите сколько соланы оставлять на кошельке. По дефолту 0.1
7. Базовое соотношение - Отношение левой монеты пула к правой. Записывать как 80/20 или 80. При пустой ячейке, т.е по дефолту отношение 50/50
8. Левое и правое отношения - Новое отношение монет пула при его закрытии в левую и правую сторону соответственно. При пустом значении будет открыт пул с DesiredRatio. Записывается так же, как и с базовым.
9. Прокси - заполните в формате host:port:user:pass - если прокси нет под приватный ключ, оставляйте пустую ячейку
10. SAP - ставьте, если вы хотите, чтобы эта позиция свапала после закрытия при закрытии всех аккантов. По дефолту токены свапаются
11. Свап в.. - в какой из монет пула делать свап после закрытия позиции
12. OnlyUp - режим, при котором позиция не будет закрываться в убыток определенное время (OnlyUpTimer из конфига)
13. TP/SL - тейк профит и стоп лосс для щитка в USDC (уникально для полной версии)
14. Imbalance - на сколько бинов от бина открытия должен падать центр позиции. То есть, если вы хотите больше места слева от открытия, ставьте отрицательный дисбаланс. \
    **Если в конфиге включен alwaysBalancedPositions - то эта настройка ни на что не влияет**
15. SaveFees - заработанные фисы НЕ БУДУТ вноситься в позицию. Очень полезная функция)
16. Клеймить и вносить комиссии - будут ли клеймится комиссии каждые N (claimFeesTimerInTicks) тиков и вносится в позицию
17. Свапать комиссии левой монеты - склеймленные комиссии щитка будут фиксироваться в солану, таким образом позиция будет пополняться исключительно соланой.
18. Уникальная RPC нода - ссылка на ноду, которую вы хотите использовать для определенного профиля. Если пустая, будет взята ссылка из конфига.

Для удаления аккаунта нажмите по нему правой кнопкой мыши

Готово! После этих шагов вы готовы запускать софт!
