# Аккаунты

## Добавление аккаунта.

Рядом с каждым полем настройки есть восклицательный знак, который показывает подсказки и назначение полей.

<div align="left"><figure><img src="../../.gitbook/assets/image (2) (1).png" alt="" width="340"><figcaption></figcaption></figure></div>

{% tabs %}
{% tab title="Private key" %}
Приватный ключ от кошелька, с которым хотите работать.
{% endtab %}

{% tab title="Pool " %}
Ссылка на пул для фарма.
{% endtab %}

{% tab title="SOL to leave" %}
Количество SOL, которое останется на аккаунте. (нужно для комиссий, не рекомендуется ставить меньше 0.052)\
Например у вас на аккаунте 2.1 SOL. Вы вписываете 0.1 в поле и в пул зайдут 2 соланы, перед этим свапнувший по заданному Ratio.
{% endtab %}
{% endtabs %}

<div align="left"><figure><img src="../../.gitbook/assets/image (3).png" alt="" width="336"><figcaption></figcaption></figure></div>

{% tabs %}
{% tab title="Bins" %}
Количество бинов в позиции, которую вы открываете (от 1 до 69).
{% endtab %}

{% tab title="Strategy" %}
Тип стратегии: Spot, Curve или BidAsk.
{% endtab %}

{% tab title="Pool Slippage" %}
Максимальный слипаж для открытия пула. Рекомендуемый 1%-5%.
{% endtab %}

{% tab title="Only-Up" %}
Если эта опция включена, позиции будут открываться только при восходящем тренде (вправо), что снижает риск падения. Позиции будут открываться снова после истечения времени «Only-up timer» (из конфигурации).
{% endtab %}
{% endtabs %}

<div align="left"><figure><img src="../../.gitbook/assets/image (4).png" alt="" width="338"><figcaption></figcaption></figure></div>

Ratio settings отвечает за распределение средств во время открытия и переоткрытия позиций

{% tabs %}
{% tab title="Default" %}
Соотношение при первом открытии пула. 50 для открытия 50/50.
{% endtab %}

{% tab title="Left" %}
Соотношение при переоткрытии пула при закрытии влево. Например вы можете выставить 0, и тогда при закрытии пула влево, вы не будете продавать токены а откроете пул со всеми токенами, которые вы уже купили.
{% endtab %}

{% tab title="Right" %}
Соотношение при переоткрытии пула при закрытии вправо. Например вы можете выставить 0, и вы не будуте покупать токен, а встанете всей имеющейся соланой вниз.
{% endtab %}
{% endtabs %}

<div align="left"><figure><img src="../../.gitbook/assets/image (5).png" alt="" width="341"><figcaption></figcaption></figure></div>

{% tabs %}
{% tab title="Proxy" %}
Можете добавить прокси к аккаунту. Рекомендуется использоваться при 5+ аккаунтах в работе.
{% endtab %}

{% tab title="SAP" %}
При закрытии через кнопку **Close**, на вкладе **Launch**. Софт будет обменивать все токены на выбранный токен. Выбирается токен из двух, которые есть в пуле в поле **Swap to...**
{% endtab %}

{% tab title="TP/SL" %}
Можете выставить цену за токен (в USDC), при которых софт будет прекращать работу с аккаунтом.
{% endtab %}
{% endtabs %}

{% tabs %}
{% tab title="Save Fees" %}
Если включено, софт при переоткрытии не будет трогать фисы, и они будут накапливаться.
{% endtab %}

{% tab title="Claim and add fees" %}
Если включено, софт будет клеймить и добавлять фисы в открытую позицию. Переодичность берется из "Fee claim timer" в настройках. Если "Save Fees" включено, то фисы будут клеймится, но не будут добавляться в позицию.\
**Swap Fees of the left coin** — Если включено, то перед добавлением фисов в позицию, левый токен будет свапнут в правый (обычно токен в солану, при позиции "shitcoin"-SOL).
{% endtab %}

{% tab title="Uniq RPC" %}
Можно добавить отдельную рпс для аккаунта. По дефолту берется RPC из Confuguration.
{% endtab %}
{% endtabs %}

После настройки важно нажать SAVE.

{% endhint %}
