# Перед работой

После установки приложения вам потребуется настроить конфигурацию и аккаунты для дальнейшей работы софта.

{% stepper %}
{% step %}
#### Настройка конфигурации (вкладка [Configuration](settings.md))

Главное поле для ввода в самом начале - [RPC URL](settings.md#rpc-node), подробнее об остальных [здесь](settings.md)
{% endstep %}

{% step %}
#### Настройка профилей (вкладка [Profiles](profiles.md))

Настройте ваши [аккаунты ](accounts.md)и [профили](profiles.md) (наборы других настроек или аккаунтов). Для работы нескольких профилей одновременно необходимо открыть несколько вкладок софта
{% endstep %}

{% step %}
#### Главная страница (вкладка [Launch](launch.md))

После настройки всех интересующих настроек можно приступать к запуску аккаунтов и началу фарма! \
О возможностях старта в разных режимах [здесь](launch.md), а во время фарма можно [следить за пулами и пнлами аккаунтов прямо на их карточках!](account-card.md)
{% endstep %}
{% endstepper %}
