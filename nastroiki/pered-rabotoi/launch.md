# Кнопки старта

Start Autofarm — запускает автофарм на всех аккаунтах, в зависимости от настроек автофарма.\\

Варианты старта аккаунтов

{% tabs %}
{% tab title="Start" %}
Запускает в работу аккаунты из выбранного профиля, открывая ОДНУ позицию на каждом аккаунте.
{% endtab %}

{% tab title="Start 3" %}
Создает связку из ТРЕХ позиций на каждом аккаунте таким образом, что занимается больший ценовой диапазон, то есть три пула идут друг за другом.\
Оптимально для использования в пулах с низким BinStep, чтобы захватить больший прайсрендж.\
Переоткрытие позиции происходит при закрытии какого-то из крайних пулов.\
Работает только на споте (пулы будут создавать 50 на 50), либо в бидаске.\
\
Например, создается три позиции, они идут подряд (по прайс ренджу) 1-2-3,\
2 пул изначально активный, если цена уходит за 3 пул вправо, то 1 пул закрывается и создается новый пул,\
2-3-4, если цена уходит влево за 2 пул, то создается 5 пул ->\
5-2-3 и т.д.\
То есть этот режим позволяет брать больший прайс рендж при маленьком бинстепе.
{% endtab %}

{% tab title="Start 5" %}
Создает связку из ПЯТИ позиций на каждом аккаунте таким образом, что занимается больший ценовой диапазон, то есть пять пулов идут друг за другом.\
Оптимально для использования в пулах с низким BinStep, чтобы захватить больший прайсрендж.\
Переоткрытие позиции происходит при закрытии какого-то из крайних пулов.\
Работает только на споте (позиции будут открываться 50 на 50), либо в бидаске\
\
Например, создается 5 позиций, они идут подряд (по прайс ренджу) 1-2-3-4-5,\
3 изначально активная, если цена уходит за 5 вправо, то 1,2 закрываются и создаются две новые позиции, 3-4-5-6-7, теперь 5 активная позиция, если цена уйдет опять влево за 3 позицию, то 6,7 закрываются и создаются новые два пула слева -> 8-9-3-4-5 и т.д.\
То есть этот режим позволяет брать больший прайс рендж при маленьком бинстепе.
{% endtab %}
{% endtabs %}
