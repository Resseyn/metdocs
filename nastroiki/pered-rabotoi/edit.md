# Быстрое редактирование

Fast Edit — позволяет отредактировать все пулы разом. ВСЕ настройки, которые вы там выставляете будут применены ко ВСЕМ аккаунтам.\
Global Pool — Позволяет поменять пул на всех аккаунтах в профиле.
