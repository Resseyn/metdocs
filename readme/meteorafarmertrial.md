# MeteoraFarmerTrial

Бесплатная версия — это полноценный софт, который можно использовать 7 дней. Все функции доступны, никаких ограничений по возможностям нет.

В бесплатном периоде действует комиссия 2.5% с фисов. Например, если в пуле заработали $100, то при выводе получите $97.5 — комиссия удерживается автоматически.

Активировать бесплатную версию можно только один раз на человека. Если попытаться обойти это правило, все ключи будут заблокированы — и бесплатные, и купленные.

Бесплатный период — удобный способ спокойно попробовать программу и понять, подходит ли она вам.
