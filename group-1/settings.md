# Settings

<figure><img src="../.gitbook/assets/image (1).png" alt="" width="476"><figcaption></figcaption></figure>

{% tabs %}
{% tab title="RPC NODE" %}
Вставьте свою ноду, подробнее [здесь](quick-start.md#rpc-node)
{% endtab %}

{% tab title="Priority Fee" %}
Комиссия за транзакции, указывается в Lamports ([конвертер](https://www.solconverter.com/)).\
Если транзакция не проходит, софт увеличивает комиссию на 20%.\
Рекомендуемое значение 200001.&#x20;
{% endtab %}

{% tab title="JUP swap slippage" %}
Максимально допустимый слипаж цены для обменов через Jupiter

Более высокое значение увеличивает вероятность успешного обмена, но может привести к менее выгодным ценам.

Если транзакция не проходит, бот автоматически увеличивает проскальзывание, поэтому можно установить значение 1% — в итоге обмен будет выполнен успешно, но с нескольких попыток.
{% endtab %}

{% tab title="Tick Time" %}
Длительность 1 тика в секундах. Требуется для остальных настроек.
{% endtab %}
{% endtabs %}

{% tabs %}
{% tab title="Time between account starts (sec)" %}
Пауза между запуском нескольких аккаунтов. Используется для ограничения по запросам на ноду, чтобы не вызывать рейтилимиты на ноде.
{% endtab %}

{% tab title="OnlyUp mode time (min)" %}
Сколько ждать (в минутах) перед тем, как переоткрыть позицию, если она вышла из ренжа, и включен OnlyUp мод.
{% endtab %}

{% tab title="Reopen Latency (ticks)" %}
Количество тиков ожидания перед повторным открытием позиции после ликвидации.&#x20;

Позволяет избежать быстрого циклического открытия и закрытия позиций в при большой волатильности.
{% endtab %}

{% tab title="Fee Claim timner (ticks)" %}
Раз в сколько тиков клеймить фисы с позиции (если эта настройка включена).
{% endtab %}
{% endtabs %}
