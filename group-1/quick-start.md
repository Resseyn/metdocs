# Quick Start

## Оформление подписки

Софт предоставляется по месячной подписке. Актуальную цену можно узнать на [сайте](https://meteorafarmer.shop/). Для оплаты нужно авторизоваться через телеграмм на сайте, далее оплатить удобным способом.\
После оплаты подписки в личном кабинете (Dashboard) появляется возможность скачать актуальную версию, посмотреть свой ключ и все что связано с софтом (подробнее здесь).

## Установка

Скачать софт можно из личного кабинета на сайте, или из телеграмм бота [@meteora\_shopbot](https://t.me/meteora_shopbot). \
После установки, запустите софт через ярлык на рабочем столе. \
При первом открытии софта у вас попросит ключ, который можно найти в [телеграмм боте](https://t.me/meteora_shopbot), или личном кабинете на [сайте](https://meteorafarmer.shop/). Ключ привязывается к устройству, то есть одновременно можно использовать софт только на одном устройстве. Отвязать ключ можно в боте, либо в личном кабинете на сайте.\
После запуска софта можете перейти к настройке.
